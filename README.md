# 5LIM3STACKDEVS Portfolio

A live, deployed full-stack personal portfolio and client acquisition platform.

🔗 Live: [slimestackdevs.com](https://slimestackdevs.com)

## What it does

Beyond a static showcase, this portfolio is a working full-stack application: it handles real client inquiries securely, protects itself against abuse, and gives the site owner an admin view into incoming activity — solving the problem of turning a personal site into an actual functioning business tool rather than just a resume page.

## Features

- Responsive frontend showcasing projects and services
- Backend API for secure contact form handling
- Rate limiting to prevent abuse/spam
- Admin dashboard for managing inquiries
- Custom domain configured via Namecheap DNS

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, React
- **Backend:** Node.js, Express
- **Deployment:** GitHub Pages (frontend), Render (backend)
- **DNS:** Namecheap

## Setup

\`\`\`bash
git clone https://github.com/5LIM3/slimestackdevs-portfolio.git
cd slimestackdevs-portfolio
npm install
cp .env.example .env
npm run dev
\`\`\`
